# Contributing

Contributions are welcome. Open an issue for significant changes before implementation. Follow [`AGENTS.md`](AGENTS.md) and the architecture and security documentation under [`docs/`](docs/).

- Use English for all code, docs, tests, comments, and pull requests.
- Create a feature branch; do not push directly to `main`.
- Keep pull requests narrow, with rationale, tests, and security impact.
- Run `./mvnw verify` with Java 25; note any verification gaps.
- Never include credentials, personal files, or environment-specific infrastructure details.
- Update an ADR when changing a foundational decision.

By submitting a contribution, you agree that it may be distributed under Apache License 2.0.
